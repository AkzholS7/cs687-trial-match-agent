Agent trace

Prototype for demonstration only. It uses synthetic sample trials (IDs start with DEMO) and example patients, stores no patient data, and only suggests matches. Final eligibility decisions belong to the clinician. Retrieval here uses BM25 and TF-IDF vectors; the full system uses sentence embeddings and LLMs for the criterion checks.
